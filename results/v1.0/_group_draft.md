v1.0 协议第一批结果（v0.1 规模：3 个卖家，后续由 40 卖家主表替换；Q 已按协议末尾的口径补正重算）：
1. 回归门槛通过：seed 0–2 重跑，和冻结的 T2_episodes.jsonl 逐项一致（1350 个值，最大差 0）。
2. T2 头条：bandit 靠回避压低 E，标签变稀疏后回避失效，E 随之上升；被回避、没有成交时 Q 无法识别，本设定不支持关于威慑的结论。
3. E 的数字（20 seed，配对 bootstrap 95% 区间，Holm 校正）：PILOT 从 π=1 的 0.046 升到 π=0.05 的 0.123、π=0 的 0.684；StageRoute 从 0.014 升到 0.063（π=0.05）、0.083（π=0）。和 π=1 比，PILOT 在 π≤0.2 都显著，StageRoute 在 π≤0.12 显著。D3 参考基线的 E 不随 π 变（0.106），这是构造性质。
4. Q（在场轮次的不加权均值，q_swap、q_theft 简单平均）：PILOT 0.88–0.94，和 π=1 比没有显著变化。StageRoute 0.67–0.93，在 π=0.06、0.05、0 时显著高于 π=1，但 π=0.06、0.05 只有 10% 的 run 尾段有成交，不能解读为威慑变化。尾段有成交的 run 比例：StageRoute 在 π>0 时 0–15%，PILOT 75–100%，D3 100%。
5. π* 判读规则（跑前写死，未改）：0.12 处 ΔJ 区间整体小于 0（[−0.062, −0.014]），0.10 处也整体小于 0（[−0.044, −0.007]），不满足条件，所以 (0.10, 0.12) 不保留，改写为条件区间加逐 seed 分布。20 个 seed 的交叉点分散在 (0, 0.05) 到 (0.2, 1.0)，只有 2 个落在 0.10–0.12。
6. A2：开合规过滤时违规率为 0；同一路由器关掉过滤后，违规率约 0.13（StageRoute、PILOT）和 0.22（最便宜），成交率基本不变。D3 没有关过滤的版本，补一个策略 id 归 @Coding。
7. hedge 学习规则下的 Q 排序检查只放附录，不算晋升门槛；正式门槛等 40 卖家规模，用 EXP3 或 fictitious play 按每个 π 判。
