# Statistical conventions — documentation version 1 (2026-11-15)

This is an index of existing analysis behavior, not a new analysis or change to locked Decision A wording. Seed-level uncertainty describes simulation variability conditional on the configured roster and reused task pool. It does not quantify uncertainty over real markets, datasets, model checkpoints or jurisdictions. T4 separately resamples rosters per run and still shares tasks/cache across its train/test run split.

For the bootstrap sign-tail tests, code uses `min(1, 2*min(P*(delta<=0), P*(delta>=0)))`; these are tests of paired differences, not tests from overlap of marginal confidence intervals. Holm is step-down, monotone and capped at one; stored zero p-values are finite-resampling outputs. The paper's existing resolution/bound notation and significance markers are unchanged.

A no-tail-trade run can still have a Q value; the v1.0 analyzer does not silently discard such Q values from means. The method-level tail-trade screen determines which methods enter the gate, and which Q contrasts are testable in later analyzers. Suspension rounds are excluded during Q construction; they are not additional statistical resamples. See [METRICS_INTERPRETATION](METRICS_INTERPRETATION.md).

Recorded comparison tolerance: `scripts/v1.1/compare_repro.py` defaults to absolute numeric difference ≤1e-9 and exact text equality. This applies to its keyed per-seed reproduction comparison, not every table, plot or CI. Other unrecorded tolerances are **not recorded**. Pass 17 used exact parsed results / byte equality where stated in [L2_REPORT.json](L2_REPORT.json), without imposing a new scientific tolerance.
