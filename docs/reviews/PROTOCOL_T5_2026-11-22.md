## 0. 任务定义

**T5：Task-conditioned model/seller recommendation under price, quality, and compliance。**

决策问题：每个任务实例，在合规硬过滤后的可买集合里，推荐 **恰好一名** 卖家（因而也确定其申报模型）。不允许组合采购。目标是在预测质量达标的前提下，选择预期 billed cost 最低的可买卖家。这对应审阅中的监督方案 **A**（更贴近「给定任务、以最优价格推荐买哪个模型」）。方案 B 的效用学习器 **不作为官方主方法**，也不在看过测试结果后再改用。

T1/T2 比较的是在线市场策略；T4 预测卖家在后续窗口是否欺诈。T5 是在仿真日志上训练、给定当前任务后做一次推荐。不得把 T1/T2/T4 改写成已经满足本任务。

## 2. 特征白名单、黑名单与泄漏检查

行单位是一次任务级决策：`(run_id, task_id)` 上的候选卖家。只用决策时可观察、且属于决策前窗口的信息。历史特征只用 **同一 run 中更早轮次**。

**白名单（锁定）：**

- 任务侧：`task_type`、`difficulty`、`sensitivity`、买家辖区、剩余预算、`consent`。
- 卖家侧：`claimed_model`、`list_price`、`listed_quality`（若按难度有挂牌值则用对应该任务难度的值，否则用已有均值口径）、卖家辖区、过滤后是否可买、决策前窗口的历史成交笔数、历史 billed-token 均值、历史成交份额。

**禁止作为特征（黑名单）：**

- `actual_model`、`tokens_actual` 及其与 billed 的差、任何 `attack` 字段、`learned_q_*`、审计 hit/miss/`label_correct`/`fraud_realized`、`slash_amount`、`delist_rounds`、`confidence`。
- 当前查询尚未发生的真实服务延迟。
- 黄金对错、prompt 全文、prompt hash、`pool_task_id`、原始 `seller_id` / `seller_key`（后两者只作连接键，不进学习器）。对错只作训练标签或评估，不作测试特征。

开跑前把白名单/黑名单写入检查脚本（体例对齐 `scripts/check_t4_leakage.py`）。**泄漏检查不过关不得评分。** 不得把试跑数字写进论文或用来反推本协议。

## 3. 监督信号、阈值 τ 与预期费用

官方学习器只训练 **P(correct ∧ ¬attacked | 白名单特征)**，再按价格筛选。

- 训练标签只来自行为策略日志里 **已成交** 的购买：若该任务最终答案相对黄金正确（与现有任务级 `quality` / accuracy 口径一致，无答案计为不正确），且该笔成交未被攻击，则 y=1，否则 y=0。未成交任务不进入训练行。
- 不使用缓存回放或反事实攻击结果来扩增官方训练集（mock 与策略攻击不是确定性可回放标签）。
- **预期 billed cost**（决策时）：`list_price × expected_billed_tokens / 1000`。`expected_billed_tokens` 取同一 `claimed_model` 在该 run 决策前窗口的 billed-token 均值；若缺，则用 **拟合折** 训练集中该 `claimed_model` 的均值；再缺则用拟合折全局均值。禁止用测试 run 拟合，也禁止用 `tokens_actual`。

**τ 只在训练集上冻结，且每个学习器分别选择、分别冻结：**

- 内分：seeds 0–9 拟合分类器；seeds 10–13 选 τ。
- 候选网格：{0.50, 0.55, 0.60, 0.65, 0.70, 0.75, 0.80, 0.85, 0.90}。
- 选则规则：在 seeds 10–13 上，于 accuracy **不低于同一内验证集上 strongest eligible** 的 τ 之中，选 `cost_per_task` 最低者；并列取更低的 τ。若没有任何 τ 达到该准确率地板，则选内验证 accuracy 最高的 τ；再并列则更低成本、再并列更低 τ。
- 若某任务在合规可买集合非空、但没有卖家满足 p≥τ，则回退为可买集合中预测 p 最高者（并列按 §4 平局规则）。可买集合为空则该任务未成交。
- τ 选定后，用 seeds 0–13 重拟合分类器，**不再重选 τ**。测试 seeds 不得参与拟合、选 τ 或任何超参决定。

学习器超参与 T4 默认值对齐，不做测试集搜索：逻辑回归 L2=1、无惩罚截距、Newton/IRLS、最多 50 次迭代、步长绝对值 <1e-8 停止；GBDT 为 logistic 损失、100 棵树、学习率 0.1、深度 3、叶最小 5、叶 L2=1、16 个分位候选阈，确定性、无行/列子采样。

**在日志上训练的协议基线（这才是第 3 点要求的组件）：**

1. Two-stage LR：逻辑回归估计 p，再在 p≥τ 的合规可买集合中选预期 billed cost 最低者。
2. Two-stage GBDT：同样的两阶段规则，分类器换为 GBDT。

**未在日志上训练的对照基线（分开报告，不得写成 T5 学习器）：**

6. 市场适配 PILOT（v1.0 已实现，继承 `scale.yaml` 的 `pilot_v1`）

平局（除 random 外）：先更低预期 billed cost（cheapest 与两阶段学习器），或先更高 `listed_quality`（strongest）；再并列则更低 `list_price`，再并列按 `seller_key` 字典序。`seller_key` 的构造与 T4 相同（`run_id|seller_id` 的 SHA256 十六进制前 12 位），只用于平局和连接，不进特征。

## 6. 指标与统计

主指标（全部报告，不选单一赢家）：任务级 accuracy（与现有 `quality` 口径一致，无答案计为不正确）、`cost_per_task`、violation_rate（与现有按任务计的合规口径一致）、E / `fraud_share`、fill_rate。同时报告准确率–成本的描述性帕累托图（测试 seed）。

统计：测试集为 seeds 14–19（n=6，与 T4 相同，正文须写明样本量为 6 个测试 run，不是 20）。同一 seed 配对差；10,000 次 bootstrap，95% 百分位区间；配对 bootstrap 双侧 p 值。Holm 校正按每个 π、每个指标，对官方 7 方法的全部成对比较为一族，α=0.05。「显著」= Holm 后 p<0.05。点估计与区间照常全报。

**事后 oracle 遗憾只作副指标，不作选方法依据。** 定义事先写死并承认其不完整：在合规可买的 **非策略** 卖家里，用缓存可回放的正确性（Qwen 贪心缓存为确定性；缺缓存键则该卖家不进 oracle 集合）与决策时预期 billed cost，选「缓存判定正确者中预期费用最低」的卖家；若无缓存判定正确的诚实可买卖家，则按 strongest eligible 规则在诚实可买集合中取。策略卖家不进 oracle 集合（攻击是内生的）。mock 若无确定性缓存则不进。该 oracle 不是真实市场最优，也不是含攻击卖家的完全信息最优。

不把 `results/model_accuracy.md` 中未进入 ARTIFACT_MAP / 正文的数字当作官方结果或 T5 标签。
